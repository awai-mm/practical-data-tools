# 第4章 Python CLIによる全SKU採算ランク自動判定

**本章の焦点**：赤字SKU・低収益SKUの早期抽出と価格改定リスト出力

---

## 4.1 実務における課題の整理と設計方針

売上は伸びているのに手元に現金が残らない原因となる隠れコスト（決済手数料・送料負担・梱包資材・広告費・返品率）を可視化し、チャネル別の限界利益と損益分岐販売数を即座に算出する実用書＆計算機。

現場の業務フローにおいて、「赤字SKU・低収益SKUの早期抽出と価格改定リスト出力」を曖昧なまま手作業で処理していると、担当者ごとの判断ブレや集計ミスが避けられません。本章では、入力データの構造を厳密に定義し、再現性のある検算・判定プロセスへ落とし込む手順を解説します。

### 標準入力カラム定義（主キー：`sku_id`）

- `sku_id`
- `item_name`
- `channel`
- `selling_price`
- `cost_of_goods`
- `shipping_cost`
- `fee_rate_pct`
- `ad_cost_per_unit`
- `monthly_units`

---

## 4.2 自動検証・計算機能（コアロジック）

本パッケージで提供するブラウザ版ワークベンチ（`ec_margin_workbench.html`）およびコマンドラインツール（`ec_margin_cli.py`）は、以下の機能を標準搭載しています。

1. **単位あたり純利益計算**
2. **実質利益率判定**
3. **損益分岐点数量算出**
4. **SKU採算ランキング出力**

---

## 4.3 実践コマンドと運用チェックポイント

手元のCSVデータに対して一括検証と正規化を実行する場合は、以下のコマンドを使用します。

```bash
/usr/bin/python3 ec_margin_cli.py samples/problem_data.csv \
  --key sku_id \
  --fix \
  --output-csv samples/verified_output.csv \
  --output-json samples/report.json
```

### 現場導入時の確認事項

| 確認フェーズ | 点検項目 | 合格基準 |
| :--- | :--- | :--- |
| **1. 入力データ受領時** | 必須カラム（全9列）の存在と主キー `sku_id` の一意性 | 欠損列0件・重複キー0件 |
| **2. 数値・日付正規化** | 全角数字・カンマ・通貨記号・前後空白の除去 | 型変換エラー0件 |
| **3. 業務ロジック検算** | 赤字SKU・低収益SKUの早期抽出と価格改定リスト出力に関する閾値および計算整合性 | 指摘エラー0件（終了コード `0`） |
| **4. 証跡保存** | 修正前後の差分確認とJSONレポートの保管 | 月次フォルダへの保存完了 |
