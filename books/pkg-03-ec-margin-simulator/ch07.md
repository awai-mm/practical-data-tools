# 第6章 現場で実際に起きたトラブル事例と完全復旧ケーススタディ

売上が増えているのに利益が残らないとき、最初に疑うべきものは販売数量ではない。販売価格、費用の集計範囲、売上と返品を認識する時点がそろっているかを確認する。価格表の計算が正しくても、入力する数字の意味が部署ごとに異なれば、赤字商品を売り伸ばす判断につながる。

本章の3事例は、実務で起こり得る障害を検証用の条件と数値で再構成したものであり、特定企業の実績ではない。金額は税抜相当の管理会計値に統一し、税額計算や端数処理の差は切り離している。実際の復旧では、契約上の手数料計算対象と請求書の丸め規則を別途確認する。

## 6.1 復旧前にそろえるデータの意味

必須カラムは、単に埋まっていればよいわけではない。次の定義を、販売担当、経理担当、データ担当で共有する。

| カラム | 本章で用いる意味 | 主な確認対象 |
|---|---|---|
| `sku_id` | 商品を一意に識別する文字列 | 先頭ゼロ、旧商品コード |
| `item_name` | 商品名称 | 名称だけで結合していないか |
| `channel` | 販売チャネル | 表記の揺れ、店舗の混同 |
| `selling_price` | 値引き後、返品前の商品単価 | 定価の混入 |
| `cost_of_goods` | 販売1個当たりの商品原価 | 仕入時点、原価改定 |
| `shipping_cost` | 販売1個に配賦した往路送料 | 注文単位との混同 |
| `fee_rate_pct` | 商品売上に対する手数料率 | 8%を8と記録しているか |
| `ad_cost_per_unit` | 広告費を販売数量で割った額 | 獲得件数との混同 |
| `monthly_units` | 月内の返品前販売数量 | 返品控除後数量の混入 |

返品、梱包材、注文単位の固定手数料は、この9項目だけでは十分に表現できない。無理に商品原価へ押し込まず、追加列または別台帳で保持する。

基本となる1個当たり限界利益は、次の式で求める。

> 限界利益＝販売単価−商品原価−送料−販売単価×手数料率÷100−広告費

この式が扱わない費用がある場合、計算結果には「基本限界利益」と表示する。最終的な採算判断には、梱包材や返品による減益などを追加で反映する必要がある。

## 6.2 事例1：手数料率の単位違いで、赤字販売を好調と判断した

### 発生した状況と数値

モールの商品データを新しい価格計算表へ移した際、手数料率8%が`0.08`として取り込まれた。計算表は`8`を想定していたため、手数料をさらに100で割っていた。

対象商品の月間販売数は1,500個。商品原価1,600円、送料450円、広告費300円、梱包材100円で販売していた。

| 項目 | 誤った計算 | 復旧後の計算 |
|---|---:|---:|
| 販売単価 | 2,500円 | 2,500円 |
| 手数料率の入力値 | 0.08 | 8 |
| 1個当たり手数料 | 2円 | 200円 |
| 梱包材込み限界利益 | 48円 | −150円 |
| 月間限界利益 | 72,000円 | −225,000円 |

利益の見込みと実態には月297,000円の差があった。売上ランキングでは上位だったため、担当者は広告予算を増やそうとしていた。しかし追加販売1個ごとに150円の損失が増える状態だった。

### 原因分析

直接原因は百分率と小数の取り違えである。管理上の原因は、移行元と移行先で同じ「手数料率」という列名を使いながら、単位を契約として定義していなかったことにある。

また、入力値が0以上100以下であるという検査だけでは、`0.08`を異常と判定できない。値域検査と意味の検査は別である。チャネルごとに契約料率を登録し、取り込み値との差を確認する必要があった。

### 完全復旧までの手順

まず広告増額を停止し、対象商品と同じ変換処理を通った全商品を抽出した。元ファイルを保存したうえで料率を修正し、過去3か月を再計算した。過去の報告値は上書きせず、訂正版と差額表を作成した。

次に、値引き後単価を2,800円へ変更する案を試算した。手数料は224円となり、梱包材込み限界利益は126円に改善する。販売数が1,200個まで減る想定でも、月間限界利益は151,200円となる。

この商品群に割り当てる月間固定費が120,000円なら、損益分岐販売数は次のとおりである。

> 120,000÷126＝952.38… → 953個

ただし、値上げ後も広告費が1個300円に収まるとは限らない。価格変更後は販売数だけでなく、広告費総額と販売1個当たり広告費を確認した。

### 再発防止

1. 項目名に`_pct`を付け、8%は`8`とする仕様を明文化する。
2. 料率は有効開始日付きのチャネル別マスターと照合する。
3. 代表商品を請求明細と突き合わせ、1個当たり手数料を検算する。
4. 修正対象期間、修正理由、実行者、承認者を変更記録に残す。

復旧完了の条件は、計算表の修正だけではない。請求明細との差が説明でき、広告判断と価格判断に使う資料が訂正版へ切り替わったことまで確認する。

## 6.3 事例2：注文単位の送料を商品行へ重複計上した

### 発生した状況と数値

直販サイトでは、同じ商品を2個ずつ購入した注文が月600件あった。実際の出荷は600箱で、1箱の送料は600円、梱包材は120円だった。

ところが集計処理は、注文データと商品明細を結合した後、各商品に送料600円と梱包材120円を計上していた。その結果、販売1,200個に対して1,200箱分の費用を記録した。

| 項目 | 誤集計 | 正しい配賦 |
|---|---:|---:|
| 販売数量 | 1,200個 | 1,200個 |
| 出荷箱数 | 1,200箱相当 | 600箱 |
| 月間送料 | 720,000円 | 360,000円 |
| 月間梱包材費 | 144,000円 | 72,000円 |
| 1個当たり送料 | 600円 | 300円 |
| 1個当たり梱包材費 | 120円 | 60円 |

販売単価2,000円、原価900円、手数料率5%、広告費200円の場合、誤った限界利益は80円、正しい限界利益は440円となる。月間限界利益は96,000円から528,000円へ訂正された。

### 原因分析

原因は、注文と商品でデータの粒度が異なることだった。注文に1つ存在する金額を商品明細へ結合すると、商品行の数だけ金額が複製される。

ここで単純に注文番号の重複を削除すると、複数商品を含む注文の一部が消えてしまう。修正すべきなのは行数ではなく、費用をどの単位で保持し、どう商品へ配るかという設計である。

### 完全復旧までの手順

送料は出荷番号単位の台帳へ戻し、商品明細とは配賦表を介して結合した。この事例では同じ商品を2個ずつ送っていたため、数量で均等に配賦した。

重量差の大きい商品を同梱する場合は、重量や容積を配賦基準にする。ただし、商品によって都合のよい方法を毎月選び直してはならない。適用条件と変更日を決め、変更前後を比較できるようにする。

配賦後は次の関係を注文・出荷単位で検査した。

> 商品へ配賦した送料の合計＝出荷台帳の送料

1円未満の端数が出る場合は、最大の配賦先へ差額を加えるなど、固定した方法で処理する。同じ入力から同じ結果になることが重要である。

訂正により、赤字と判断して停止していた販促を再検討できた。ただし、過去の2個同梱率が将来も続くとは限らない。1個注文では限界利益が80円まで下がるため、注文構成別の試算も残した。

### 再発防止

配賦前後の総額一致を必須検査とし、結合前後の行数、注文数、出荷数を記録する。さらに「1注文1商品」「1注文複数商品」「分割出荷」の3パターンを検証用データとして保存する。

復旧完了は、請求送料との総額一致に加え、分割出荷でも費用の欠落や重複が発生しないことを確認して判定する。

## 6.4 事例3：返品月だけが赤字になり、販売月の採算を見誤った

### 発生した状況と数値

返品を受け付ける商品で、販売月の売上だけを価格判断に使っていた。翌月の返金は経理集計に反映されていたものの、販売した商品の収益分析へ戻されていなかった。

販売単価5,000円、原価2,000円、往路送料500円、手数料率4%、広告費700円、梱包材100円の場合、返品前限界利益は1個1,500円となる。月1,000個の販売では1,500,000円に見える。

その販売分から100個が返品された。全額返金し、手数料は返還されず、返品送料600円と検品費200円を負担した。返品の80%は、追加費用なく再販可能な在庫として原価2,000円で戻せるものとする。

| 返品1件による追加の影響 | 金額 |
|---|---:|
| 商品代金の返金 | −5,000円 |
| 返品送料 | −600円 |
| 検品費 | −200円 |
| 平均在庫回復額：2,000円×80% | ＋1,600円 |
| 返品1件当たりの追加減益 | −4,200円 |

月間限界利益は420,000円減少し、1,080,000円となる。販売1個当たりでは1,080円である。往路送料、広告費、返還されない手数料は返品前の計算ですでに控除しているため、追加減益で再び引かない。

### 原因分析

返品率の分母を、その月の販売数にしていた点も問題だった。今月の返品には先月以前の販売分が含まれる。販売が急増した月は見かけの返品率が下がり、販売が減った月は上がってしまう。

返品率は販売月別の集団にひも付け、返品受付期間が経過した集団と、まだ返品が発生し得る集団を区別して見る必要がある。

### 完全復旧までの手順

注文番号と商品明細番号で返品を元の販売へ結び直し、販売月別の収支表を作成した。未確定の販売月には、条件が近い過去の販売分から推定した返品率を用い、確定値と混在させずに表示した。

月間固定費900,000円なら、返品前の損益分岐販売数600個に対し、返品を織り込んだ販売数は834個となる。返品率15%なら限界利益は870円、分岐点は1,035個まで上がる。

在庫回復1,600円は現金入金ではない。このため収益分析とは別に、返金日、返品送料の支払日、再販後の入金日を資金繰り表へ反映した。

### 再発防止と復旧の判定

返品台帳には、元販売明細、数量、返金額、受付日、在庫回復額、再販可否を記録する。部分返品や交換も区別し、同じ販売数量を超える返品登録を検知する。

復旧は、返品件数、返金総額、在庫受入数量の3つが各台帳と一致し、未突合の返品に担当者と解消期限が設定された時点で判定する。価格計算の訂正、過去報告の訂正、現場の判断基準の更新までを一連の作業として完了させる。
