# 第3章 単一HTML 12ヶ月資金繰り・ランウェイ計算機の活用

**本章の焦点**：月次収支計画CSVから月末残高と安全月数を即時表示

---

## 3.1 実務における課題の整理と設計方針

損益計算書（PL）上の利益と実際の口座残高のズレを生む入金サイト・支払サイト・消費税や所得税の納税月を織り込み、資金ショート危険月を事前に検知する実務書＆計算機。

現場の業務フローにおいて、「月次収支計画CSVから月末残高と安全月数を即時表示」を曖昧なまま手作業で処理していると、担当者ごとの判断ブレや集計ミスが避けられません。本章では、入力データの構造を厳密に定義し、再現性のある検算・判定プロセスへ落とし込む手順を解説します。

### 標準入力カラム定義（主キー：`month_id`）

- `month_id`
- `opening_cash`
- `cash_inflow`
- `fixed_outflow`
- `variable_outflow`
- `tax_reserve_outflow`
- `closing_cash`

---

## 3.2 自動検証・計算機能（コアロジック）

本パッケージで提供するブラウザ版ワークベンチ（`cashflow_runway_workbench.html`）およびコマンドラインツール（`cashflow_runway_cli.py`）は、以下の機能を標準搭載しています。

1. **月末残高（opening + in - out == closing）検算**
2. **月次フリーキャッシュフロー算出**
3. **納税引当後の安全運転資金判定**
4. **検証済み資金繰りCSV出力**

---

## 3.3 実践コマンドと運用チェックポイント

手元のCSVデータに対して一括検証と正規化を実行する場合は、以下のコマンドを使用します。

```bash
/usr/bin/python3 cashflow_runway_cli.py samples/problem_data.csv \
  --key month_id \
  --fix \
  --output-csv samples/verified_output.csv \
  --output-json samples/report.json
```

### 現場導入時の確認事項

| 確認フェーズ | 点検項目 | 合格基準 |
| :--- | :--- | :--- |
| **1. 入力データ受領時** | 必須カラム（全7列）の存在と主キー `month_id` の一意性 | 欠損列0件・重複キー0件 |
| **2. 数値・日付正規化** | 全角数字・カンマ・通貨記号・前後空白の除去 | 型変換エラー0件 |
| **3. 業務ロジック検算** | 月次収支計画CSVから月末残高と安全月数を即時表示に関する閾値および計算整合性 | 指摘エラー0件（終了コード `0`） |
| **4. 証跡保存** | 修正前後の差分確認とJSONレポートの保管 | 月次フォルダへの保存完了 |
