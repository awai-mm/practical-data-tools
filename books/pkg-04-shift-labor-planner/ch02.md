# 第1章 勤怠締め日に発覚する打刻漏れ・休憩不足の防止策

**本章の焦点**：シフト段階と実績段階の2段階チェック

---

## 1.1 実務における課題の整理と設計方針

6時間超・8時間超の法定休憩漏れ、深夜割増・残業時間の計算ミス、売上予測に対する日次人件費率の超過をシフト確定前に一発検査する実務解説書＆ツールパック。

現場の業務フローにおいて、「シフト段階と実績段階の2段階チェック」を曖昧なまま手作業で処理していると、担当者ごとの判断ブレや集計ミスが避けられません。本章では、入力データの構造を厳密に定義し、再現性のある検算・判定プロセスへ落とし込む手順を解説します。

### 標準入力カラム定義（主キー：`shift_id`）

- `shift_id`
- `work_date`
- `staff_id`
- `staff_name`
- `work_minutes`
- `break_minutes`
- `hourly_wage`
- `daily_sales_target`

---

## 1.2 自動検証・計算機能（コアロジック）

本パッケージで提供するブラウザ版ワークベンチ（`shift_labor_workbench.html`）およびコマンドラインツール（`shift_labor_cli.py`）は、以下の機能を標準搭載しています。

1. **法定休憩時間（6h超45分・8h超60分）検査**
2. **残業時間および概算人件費計算**
3. **売上目標比の人件費率算出**
4. **修正済み勤怠CSV出力**

---

## 1.3 実践コマンドと運用チェックポイント

手元のCSVデータに対して一括検証と正規化を実行する場合は、以下のコマンドを使用します。

```bash
/usr/bin/python3 shift_labor_cli.py samples/problem_data.csv \
  --key shift_id \
  --fix \
  --output-csv samples/verified_output.csv \
  --output-json samples/report.json
```

### 現場導入時の確認事項

| 確認フェーズ | 点検項目 | 合格基準 |
| :--- | :--- | :--- |
| **1. 入力データ受領時** | 必須カラム（全8列）の存在と主キー `shift_id` の一意性 | 欠損列0件・重複キー0件 |
| **2. 数値・日付正規化** | 全角数字・カンマ・通貨記号・前後空白の除去 | 型変換エラー0件 |
| **3. 業務ロジック検算** | シフト段階と実績段階の2段階チェックに関する閾値および計算整合性 | 指摘エラー0件（終了コード `0`） |
| **4. 証跡保存** | 修正前後の差分確認とJSONレポートの保管 | 月次フォルダへの保存完了 |
