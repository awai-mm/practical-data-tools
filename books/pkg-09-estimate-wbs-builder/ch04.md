# 第3章 単一HTML WBS工数・粗利連動シミュレータの実践

**本章の焦点**：タスク一覧CSVから見積総額と粗利率を即時計算

---

## 3.1 実務における課題の整理と設計方針

実装工数だけで見積もってテスト・修正・進行管理費で赤字になるパターンを防ぎ、不確実性係数と目標粗利率から適正見積金額を算出する実務書＆計算機パック。

現場の業務フローにおいて、「タスク一覧CSVから見積総額と粗利率を即時計算」を曖昧なまま手作業で処理していると、担当者ごとの判断ブレや集計ミスが避けられません。本章では、入力データの構造を厳密に定義し、再現性のある検算・判定プロセスへ落とし込む手順を解説します。

### 標準入力カラム定義（主キー：`task_id`）

- `task_id`
- `phase_name`
- `task_name`
- `base_hours`
- `risk_multiplier`
- `hourly_rate`
- ` hourly_cost`

---

## 3.2 自動検証・計算機能（コアロジック）

本パッケージで提供するブラウザ版ワークベンチ（`estimate_wbs_workbench.html`）およびコマンドラインツール（`estimate_wbs_cli.py`）は、以下の機能を標準搭載しています。

1. **リスクバッファ込み工数計算**
2. **タスク別見積金額・原価・粗利算出**
3. **案件全体の粗利率判定**
4. **見積明細CSV出力**

---

## 3.3 実践コマンドと運用チェックポイント

手元のCSVデータに対して一括検証と正規化を実行する場合は、以下のコマンドを使用します。

```bash
/usr/bin/python3 estimate_wbs_cli.py samples/problem_data.csv \
  --key task_id \
  --fix \
  --output-csv samples/verified_output.csv \
  --output-json samples/report.json
```

### 現場導入時の確認事項

| 確認フェーズ | 点検項目 | 合格基準 |
| :--- | :--- | :--- |
| **1. 入力データ受領時** | 必須カラム（全7列）の存在と主キー `task_id` の一意性 | 欠損列0件・重複キー0件 |
| **2. 数値・日付正規化** | 全角数字・カンマ・通貨記号・前後空白の除去 | 型変換エラー0件 |
| **3. 業務ロジック検算** | タスク一覧CSVから見積総額と粗利率を即時計算に関する閾値および計算整合性 | 指摘エラー0件（終了コード `0`） |
| **4. 証跡保存** | 修正前後の差分確認とJSONレポートの保管 | 月次フォルダへの保存完了 |
