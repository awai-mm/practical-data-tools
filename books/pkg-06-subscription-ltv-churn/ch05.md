# 第4章 Python CLIによる月次コホート・継続率レポート生成

**本章の焦点**：CSVからの自動集計と健全性アラート

---

## 4.1 実務における課題の整理と設計方針

月次解約率（チャーンレート）のわずかな差が12ヶ月後のMRRとLTVに与える影響を正確に試算し、許容獲得単価（CAC）と投資回収月数を即座に判定する実務書＆計算機。

現場の業務フローにおいて、「CSVからの自動集計と健全性アラート」を曖昧なまま手作業で処理していると、担当者ごとの判断ブレや集計ミスが避けられません。本章では、入力データの構造を厳密に定義し、再現性のある検算・判定プロセスへ落とし込む手順を解説します。

### 標準入力カラム定義（主キー：`plan_id`）

- `plan_id`
- `plan_name`
- `active_users`
- `arpu_jpy`
- `gross_margin_pct`
- `monthly_churn_pct`
- `cac_jpy`

---

## 4.2 自動検証・計算機能（コアロジック）

本パッケージで提供するブラウザ版ワークベンチ（`sub_ltv_churn_workbench.html`）およびコマンドラインツール（`sub_ltv_churn_cli.py`）は、以下の機能を標準搭載しています。

1. **MRRおよび粗利LTV算出**
2. **LTV/CAC比率（3.0x基準）判定**
3. **CAC回収月数（Payback Period）計算**
4. **改善シミュレーションCSV出力**

---

## 4.3 実践コマンドと運用チェックポイント

手元のCSVデータに対して一括検証と正規化を実行する場合は、以下のコマンドを使用します。

```bash
/usr/bin/python3 sub_ltv_churn_cli.py samples/problem_data.csv \
  --key plan_id \
  --fix \
  --output-csv samples/verified_output.csv \
  --output-json samples/report.json
```

### 現場導入時の確認事項

| 確認フェーズ | 点検項目 | 合格基準 |
| :--- | :--- | :--- |
| **1. 入力データ受領時** | 必須カラム（全7列）の存在と主キー `plan_id` の一意性 | 欠損列0件・重複キー0件 |
| **2. 数値・日付正規化** | 全角数字・カンマ・通貨記号・前後空白の除去 | 型変換エラー0件 |
| **3. 業務ロジック検算** | CSVからの自動集計と健全性アラートに関する閾値および計算整合性 | 指摘エラー0件（終了コード `0`） |
| **4. 証跡保存** | 修正前後の差分確認とJSONレポートの保管 | 月次フォルダへの保存完了 |
