# 第2章 安全在庫と発注点（ROP）の実務計算式

**本章の焦点**：安全係数・調達リードタイム・日次出荷標準偏差の扱い方

---

## 2.1 実務における課題の整理と設計方針

SKUごとの出庫実績と調達リードタイムから安全在庫・発注点・推奨発注数を自動算出し、売上貢献度によるABCランク分類と滞留在庫アラートを出力する実務ハンドブック＆計算機パック。

現場の業務フローにおいて、「安全係数・調達リードタイム・日次出荷標準偏差の扱い方」を曖昧なまま手作業で処理していると、担当者ごとの判断ブレや集計ミスが避けられません。本章では、入力データの構造を厳密に定義し、再現性のある検算・判定プロセスへ落とし込む手順を解説します。

### 標準入力カラム定義（主キー：`sku_code`）

- `sku_code`
- `item_name`
- `current_stock`
- `avg_daily_demand`
- `demand_stddev`
- `lead_time_days`
- `unit_cost`
- `moq`

---

## 2.2 自動検証・計算機能（コアロジック）

本パッケージで提供するブラウザ版ワークベンチ（`inventory_reorder_workbench.html`）およびコマンドラインツール（`inventory_reorder_cli.py`）は、以下の機能を標準搭載しています。

1. **安全在庫および発注点算出**
2. **要発注アラート判定**
3. **推奨発注数（MOQ考慮）計算**
4. **ABCランク分類出力**

---

## 2.3 実践コマンドと運用チェックポイント

手元のCSVデータに対して一括検証と正規化を実行する場合は、以下のコマンドを使用します。

```bash
/usr/bin/python3 inventory_reorder_cli.py samples/problem_data.csv \
  --key sku_code \
  --fix \
  --output-csv samples/verified_output.csv \
  --output-json samples/report.json
```

### 現場導入時の確認事項

| 確認フェーズ | 点検項目 | 合格基準 |
| :--- | :--- | :--- |
| **1. 入力データ受領時** | 必須カラム（全8列）の存在と主キー `sku_code` の一意性 | 欠損列0件・重複キー0件 |
| **2. 数値・日付正規化** | 全角数字・カンマ・通貨記号・前後空白の除去 | 型変換エラー0件 |
| **3. 業務ロジック検算** | 安全係数・調達リードタイム・日次出荷標準偏差の扱い方に関する閾値および計算整合性 | 指摘エラー0件（終了コード `0`） |
| **4. 証跡保存** | 修正前後の差分確認とJSONレポートの保管 | 月次フォルダへの保存完了 |
