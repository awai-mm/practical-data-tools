# 第4章 Python標準ライブラリだけで作る自動検品・クレンジングCLI

**本章の焦点**：追加パッケージ不要でどの端末でも動くPythonスクリプトの設計、終了コードによるバッチ連携、JSONレポート出力と自動修正モード（--fix）の活用

---

## 4.1 標準ライブラリだけで実装する設計メリット

日々の定時バッチやファイル受信フォルダの自動監視に組み込むには、コマンドラインから実行できるPythonスクリプト（`csv_cleansing_cli.py`）が適しています。付属の `csv_cleansing_cli.py` は、**Python標準ライブラリ（`csv`, `json`, `re`, `argparse`, `datetime`, `unicodedata`, `pathlib`, `sys`）のみ**で実装されており、`pip install` による外部パッケージ導入が一切不要です。

- OSアップグレードや仮想環境（venv）の破損で動かなくなるリスクがない
- 終了コード（Exit Code：エラーなしなら `0`、要確認エラー検出時は `1`）を返すため、シェルスクリプトやタスクスケジューラとそのまま連携できる

---

## 4.2 基本的なコマンド実行例

### （1）問題データの検品実行（読み取り専用チェック）

```bash
/usr/bin/python3 csv_cleansing_cli.py samples/problem_sales_inventory.csv --key record_id
```

このコマンドを実行すると、元ファイルを一切書き換えずに全行の検査を行い、コンソールに検品サマリと指摘一覧を表示します。論理エラー（重複キー・金額不一致・マイナス在庫など）が1件以上ある場合は終了コード `1` で終了します。

### （2）自動クレンジング＆クリーンCSV出力（`--fix` モード）

```bash
/usr/bin/python3 csv_cleansing_cli.py samples/problem_sales_inventory.csv \
  --key record_id \
  --fix \
  --output-csv output/cleaned_sales.csv \
  --output-json output/inspection_report.json
```

`--fix` オプションを指定すると、以下の正規化・修復処理を適用したクリーンなCSVを `--output-csv` に出力します。

1. 全カラムの前後空白除去
2. 全角英数字の半角変換、金額・単価・数量の通貨記号（`¥` 等）およびカンマ除去
3. 日付フォーマットの `YYYY-MM-DD` 統一
4. 主キー重複行の除外（先勝ち保持・重複行はレポートへ記録）
5. `amount`（金額）の `quantity * unit_price` による再計算補正
6. マイナス在庫や不正日付など自動修復できない行の隔離またはフラグ記録

## 4.3 JSONレポート構造と後続処理への連携

`--output-json` で出力されるJSONファイルには、以下の構造化された検品結果が記録されます。

```json
{
  "ok": false,
  "input_file": "samples/problem_sales_inventory.csv",
  "total_rows": 8,
  "valid_rows": 3,
  "error_count": 5,
  "warning_count": 4,
  "summary_metrics": {
    "total_quantity": 95,
    "total_amount": 184500,
    "by_category": {
      "オフィス用品": {"rows": 3, "amount": 64500},
      "PC周辺機器": {"rows": 4, "amount": 120000}
    }
  },
  "issues": [
    {
      "row_number": 3,
      "record_id": "REC-1002",
      "severity": "ERROR",
      "code": "E10_AMOUNT_MISMATCH",
      "column": "amount",
      "message": "金額不一致: quantity(5) * unit_price(1200) = 6000 != amount(5000)"
    }
  ]
}
```

このJSON出力を使えば、日次の自動検品バッチで `error_count > 0` のときだけチャットやメールへ通知を送る仕組みが数十行のスクリプトで構築できます。
